# 📋 CLI To-Do List App

A lightweight, fast, and easy-to-use Command Line Interface (CLI) To-Do List application built with **TypeScript** and **Node.js**. Manage your daily tasks efficiently right from your terminal!

---

## ✨ Features

- ➕ **Add Tasks:** Quickly add new tasks to your list.
- 📑 **View Tasks:** Display all pending and completed tasks with clear formatting.
- ✅ **Mark as Done:** Toggle task status to completed.
- 🗑️ **Delete Tasks:** Remove unwanted or finished tasks easily.
- 💾 **Persistent Storage:** Saves your tasks locally so you never lose your data.

---

## 🛠️ Tech Stack

- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Runtime:** [Node.js](https://nodejs.org/)
- **Package Manager:** npm / pnpm / yarn
